First public release of **Chromotion**, a free and open-source (MIT) Chrome extension that turns tab chaos into calm Canvas workspaces.

### Highlights
- Canvases mirrored as Chrome tab groups; switch with `Ctrl/⌘ K` or `Alt 1…9`
- On-device AI grouping and naming. No cloud, no account, no API key
- Optional local open-source models (Ollama, LM Studio, llama.cpp)
- Crash-safe: survives browser and service-worker restarts
- Sleeping tabs, smooth with 100+ tabs, JSON/CSV backups, undo
- Frosted-glass UI with light and dark themes

### Install
1. Download **chromotion-0.2.0.zip** below and **extract** it
2. Open `chrome://extensions` and enable **Developer mode**
3. **Load unpacked** → choose the folder that contains `manifest.json`

**Kurulum (TR):** Zip'i bir klasöre çıkarın → `chrome://extensions` → Geliştirici modu → Paketlenmemiş öğe yükle.
